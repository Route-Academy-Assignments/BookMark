# BookMark

A simple web application to save, categorize, and manage your favorite website links.

## ✨ Features
- Add bookmarks with a name and URL.
- View a list of all saved bookmarks.
- Visit the bookmarked site directly from the app.
- Delete bookmarks you no longer need.

## 🛠️ Tech Stack
- **Front-End:** JavaScript, HTML, CSS
- **Storage:** Browser LocalStorage

## 🚀 How to Use
1. Clone this repository.
2. Open `index.html` in your browser.
3. Start adding your bookmarks!
